## `adlc eval`

```text
usage: adlc eval [-h] [--lint] [--tasks TASKS] [--repos REPOS] [--tier TIER]
                 [--task TASK] [--repo REPO] [--arms ARMS] [--runs RUNS]
                 [--results RESULTS] [--out OUT] [--dry-run]
                 [--timeout TIMEOUT] [--model MODEL]
                 [--judge-model JUDGE_MODEL] [--adoption-test REPO]
                 [--judge-only RESULTS_JSONL] [--rejudge]

options:
  -h, --help            show this help message and exit
  --lint
  --tasks TASKS         tasks dir (default: kit harness/tasks)
  --repos REPOS         dir holding the consuming repos
  --tier TIER
  --task TASK
  --repo REPO
  --arms ARMS           comma list (default per tier)
  --runs RUNS
  --results RESULTS
  --out OUT             results file name (default <date>.jsonl)
  --dry-run             stub driver + stub judge, no spend
  --timeout TIMEOUT
  --model MODEL         pin Copilot model for agent runs (default auto)
  --judge-model JUDGE_MODEL
  --adoption-test REPO  Phase 8 timed walkthrough (see adlc/adoption.py)
  --judge-only RESULTS_JSONL
                        (re)judge records in a results file; arm never passed
                        to the judge
  --rejudge             with --judge-only: re-score even already-judged
                        records
```
